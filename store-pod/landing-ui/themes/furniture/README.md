# furniture theme — The Home Floor Directory

For a **whole-home lifestyle retailer**: a broad catalogue where the rooms and departments matter as much
as the single piece. The shop is rendered as the building's own directory — departments carry floor
numbers and counts on an enamel board, product groups are numbered plates, and the same floor number
follows a shopper from the board to the department plate to a product's floor tag.

Built with impeccable's `new-work` flow (direction seed `276164e3`, code-led). The visual system is
documented in `DESIGN.md`; the contract it was built to is the comment at the top of `src/layout/Root.tsx`.
