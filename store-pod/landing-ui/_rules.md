### Rules for creating a new theme

1. no external or internal css files only use tailwind css utils
2. no new dependency added to package.json just use the
   allowed ["tailwindcss/postcss" , "@headlessui/react" , "@heroicons/react" , "swiper"]
3. use localization for any labeling and sync in all languages
4. use css colors from tailwind variables like ["bg-primary" , "bg-foreground" , "text-foreground"]
