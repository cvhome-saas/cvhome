# Dynamic Theme Tokens PR Plan

Create a PR from `main` to optimize theme loading by moving `tokens.css` imports to dynamic loading.

## Steps

1. **Branching**: Create `perf/dynamic-theme-tokens` from `main`.
2. **Commit**: Commit the changes in `store-pod/landing-ui`.
3. **Verification**: Run `npm run build` in `store-pod/landing-ui`.
4. **Push**: Push the branch to origin.
